# Dua Rehab Center HMS

This is a comprehensive Hospital Management & CRM system designed for Dua Rehab Center.

## Tech Stack
- **Backend:** Python (Flask, Flask-PyMongo, Flask-SocketIO)
- **Frontend:** Vanilla JS, Tailwind CSS CDN, HTML5
- **Database:** MongoDB (via PyMongo)
- **Real-Time:** Socket.IO / WebSockets

## Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone <repo-url>
   cd Devotion-Rehab-Center--main
   ```

2. **Set up virtual environment & install dependencies:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. **Configure Environment Variables:**
   Create a `.env` file and define `MONGO_URI`, `SECRET_KEY`, etc.

4. **Run the server:**
   ```bash
   python app.py
   ```
